# Agent 长期记忆 · 精简 PRD

日期：2026-10-30  
范围：个人、项目及当前任务的 Agent 偏好；第一期原型

## 1. 目标

让 Agent 记住用户的工作习惯、项目背景与任务要求，减少重复说明。同一项目内的后续任务可复用已保存的信息。

## 2. 入口与生效范围

| 层级 | 入口 | 生效范围 |
|---|---|---|
| 个人 | 个人中心 → Agent偏好；无项目时的 Agent 启动页 | 本人的所有 Agent 任务，作为默认偏好 |
| 项目 | 项目页顶部「Agent偏好」弹窗；项目内 Agent 启动页 | 当前项目内的 Agent 任务 |
| 当前任务 | Agent 右侧工作台 → Agent偏好 | 仅当前任务 |

冲突时按 **当前任务 > 项目 > 个人** 处理；未提及的要求继续沿用下层偏好。空文件表示无额外要求，不清除其他层级内容。不同项目及任务之间隔离。

## 3. 界面与交互

- 入口名为「Agent偏好 / Agent preferences」，内容区标题统一为 **Agent.md**。
- 使用一个文件承载内容，不拆分「指令」「记忆」「回答要求」等表单，不新增项目 Tab。
- 默认查看，点击「编辑」进入文本编辑；支持保存、取消与下载。编辑、下载位于标题右侧。
- 输入框不重复显示文件名；移除范围标签、作者/更新时间、Markdown 标签与常驻优先级说明。
- 保留一句核心说明与空白输入示例。切换中英文只改变界面文案，不翻译或改写已保存内容。
- 放弃未保存修改需确认；内容被其他操作更新时提示重新载入，禁止覆盖新版本；保存失败保留草稿。

| 位置 | 中文 | English |
|---|---|---|
| 个人说明 | 告诉 Agent 你希望它怎么回答和做事，之后每个任务都会默认采用。 | Tell Agent how you like it to respond and work. These preferences apply to all your tasks. |
| 项目说明 | 告诉 Agent 这个项目的背景和要求，项目内的任务都会采用。 | Tell Agent about this project and your requirements. These preferences apply to tasks in this project. |
| 任务说明 | 告诉 Agent 这次任务的要求，仅对当前任务生效。 | Tell Agent what you need for this task. These preferences apply only here. |
| 输入示例 | 例如：回答简洁，先给结论，引用论文时附上来源。 | For example: Keep answers concise, lead with the conclusion, and include sources when citing papers. |

## 4. 记忆读写规则

- **Agent 主要维护，用户可查看和修改。** 用户可在对话中要求「帮我记住……」「查看项目记忆」。
- 明确指定个人、项目或任务时写入对应范围；未指定时，项目内默认写入项目，无项目默认写入个人。任务记录不得自动扩散到个人层级。
- Agent 可整理已完成任务的背景和结论供后续复用；不把未核实推测写成事实。用户手动修改与 Agent 写入使用同一份内容。
- 创建任务时记录所采用的文件快照。已有任务发现更新后，可在折叠区域「本次采用的偏好」点击「采用最新偏好」。
- 旧版偏好内容迁移为同一文件，保留原文；重复写入同一条信息不重复追加。

## 5. 实现边界与后续接入

**当前原型已实现：** 浏览器本地保存、三级文件与快照、编辑/下载/冲突提示、中英文设置界面，以及中文对话关键词触发的模拟读写。浏览器研究演示结束后会模拟追加任务和项目记录。

**正式接入要求：** 服务端按用户/项目/任务持久化并鉴权，接入真实 Agent 读写和优先级处理。个人内容仅本人可访问；项目读写权限需与项目协作权限对齐，具体角色权限另行确认。原型不代表已实现跨设备或跨成员同步。

**不在本期：** 休眠设置、复杂记忆分类、历史版本管理，以及真实模型自动提炼能力。

## 6. 验收标准

1. 三个入口均能查看对应文件；项目页使用弹窗，入口名称与内容区标题符合设计。
2. 编辑保存后重新打开仍保留；取消不修改已保存内容，冲突与失败不丢失草稿。
3. 对话模拟读写命中正确范围，不污染其他项目；新任务快照包含个人、项目、任务文件。
4. 已有任务可明确采用最新文件；三级优先级与正式接入范围在实现说明中清晰区分。
5. 中英文说明、示例及操作提示完整；切换语言不改变文件原文。
6. 无重复文件标题和冗余状态说明；已有偏好可迁移读取，下载文件名为 Agent.md。
