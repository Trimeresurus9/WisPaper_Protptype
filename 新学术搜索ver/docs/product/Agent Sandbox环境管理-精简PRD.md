# Agent 云主机管理 · 精简 PRD

更新日期：2026-11-10

状态：前端原型；覆盖云主机展示、状态 Mock 与 Credits 明细。真实云主机服务与计费服务待接入。

本次会话完整需求汇总见 [云主机保留与 Credits 计费 PRD](./Agent云主机保留与Credits计费-精简PRD.md)。

## 1. 目标

Agent 云主机由「运行—删除」升级为「运行—休眠—回收」。保留任务云主机中的文件、依赖和配置，方便继续任务；通过自动休眠与回收减少空闲资源占用。

## 2. 界面与文案

工作台右上角的终止按钮替换为云主机图标按钮，点击打开「任务云主机」浮层。

| 内容 | 规则 |
| --- | --- |
| 云主机状态 | 运行中、已休眠、已回收；启动过程中显示正在唤醒／正在创建 |
| 任务运行 | 当前任务累计实际执行时长，不含等待及休眠；创建新云主机后继续累计 |
| 云主机已保留 | 当前云主机自创建以来的存续时长，包含运行及休眠；回收后冻结，新云主机重新计时 |
| 休眠后保留时间 | 状态行显示「云主机运行中 [10min 后回收 ▾]」；点击回收时间展开 10min（默认）、20min、1h、永久保留选项，单选即时生效 |

「任务云主机」标题后增加 ⓘ 图标，悬浮或键盘聚焦显示：

> 保留任务云主机中的文件、依赖和配置，方便继续任务。

运行与已保留时长降为状态行下方的弱提示，使用 min / h / d，不显示秒；不足 1 分钟显示 <1min。运行中显示所选回收策略，休眠后显示剩余分钟数（向上取整），不足 1 分钟显示 <1min 后回收。菜单标题明确「休眠后保留时间」，计时起点不变。不展示横向状态条、独立回收倒计时卡片、预计回收时间及底部常驻解释。不提供手动唤醒／重建按钮。距回收不足 1 分钟时，云主机入口以琥珀色提示。已回收时隐藏保留策略选项。

### Credits 消耗

- 右上角 Credits 总数可打开消耗明细，常驻「任务执行」和「云主机保留」两项。
- 云主机保留会产生 Credits 消耗；尚未产生消耗时也显示该项，值为 0 Credits。
- 总数等于任务执行与云主机保留的累计消耗之和。休眠、唤醒、永久保留或回收均不隐藏已产生的消耗记录。
- 原型使用固定 Mock 数值（任务执行 1,250、云主机保留 12，共 1,262 Credits），支持切换保留消耗为 0，不真实扣费或根据时长计算。
- 生产计费单价、计费起止时点、不同状态费率及扣费精度待确认，由服务端返回累计消耗。

## 3. 生命周期与保留规则

- 云主机启动后进入运行状态。Agent 执行任务期间不休眠；执行结束、暂停或等待用户后，连续空闲 1 分钟进入休眠。
- 默认休眠 10 分钟后回收。20 分钟、1 小时均从本次进入休眠时起算，不从修改设置时重新计时。
- 保留策略作用于当前任务云主机，后续休眠沿用。唤醒后结束本轮计时，下次休眠重新起算。
- 永久保留仅关闭自动回收，仍会休眠，不代表持续运行。
- 缩短时长且本轮休眠已超时：提示「应用后将立即回收云主机」，确认后回收；取消则维持原策略。
- 打开浮层、切换保留选项或编辑未发送的草稿，不触发唤醒，也不重置计时。

## 4. 发送指令自动执行

用户发送任意非空 query 后，系统按云主机状态自动处理：

| 当前状态 | 处理方式 |
| --- | --- |
| 运行中且可接收任务 | 直接执行 query |
| 已休眠 | 自动唤醒原云主机，就绪后执行同一条 query |
| 已回收 | 自动创建新云主机，就绪后执行同一条 query |

云主机准备期间展示进度、保留输入并防止重复提交；就绪后自动提交并清空输入，无需用户重复发送。休眠／已回收时输入框可用，历史暂停回答不得阻塞新指令。空白输入不提交。

## 5. 验收与上线边界

**核心验收**

1. 浮层信息、保留选项及 ⓘ 文案符合上述规则，支持键盘操作及窄屏展示。
2. 正在执行的任务不因用户未输入而休眠；空闲 1 分钟后休眠，并按所选策略回收。
3. 永久保留不自动回收；修改策略不延后休眠起点；缩短至已超时需确认。
4. 从休眠或已回收状态发送指令，均自动启动云主机并仅执行一次 query。
5. 两项时长计算正确；后台页面恢复后按实际时间更新状态。
6. Credits 明细中「云主机保留」始终可见，0 消耗与回收后均保留该项；明细之和与总数一致。

**上线前补齐／确认**

- 接入服务端状态、时间戳及策略存储；刷新页面后恢复真实云主机状态。
- 明确文件、依赖、配置的保留范围，以及云主机回收后对话与已保存成果的保留规则。
- 云主机启动或策略保存失败时，提示失败并保留 query／原策略，支持重试。
- 确认永久保留的权限与计费规则；本次不定义价格或额度。

当前原型仅模拟状态与执行流程，不创建或删除真实云主机；「原型演示」控件不属于正式产品功能。
