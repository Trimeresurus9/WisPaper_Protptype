# 首页与游客 onboarding 原型

入口：`/app/home`，侧栏「首页」。侧栏「原首页」仍进入 `/`，原页面内容保持不变。

## 本次行为

- 一个输入框与五个任务 tag。论文搜索和四类 Agent 任务均展示三个示例卡片。
- Agent 案例直接打开现有工作台里的已完成成果，支持查看过程、下一步和随时返回成果。预览不执行新任务、不消耗 Credits、不写入个人任务记录。
- 开始自己的任务时，先填写主题和可选要求，再在原页面展示模拟登录；草稿和上下文保存在当前会话中。
- 论文搜索卡片打开大图预览：主题、关键词、Prompt、4 篇论文以及 Perfect / Partial。保留「查看结果页」「像这样搜索一次」：前者进入同一组论文的现有结果页，后者回填并聚焦输入框。
- 合并时保留 main 的机构管理、反馈、任务记忆、网页执行跟踪与云主机功能。案例中的任务记忆和云主机仅禁用其副作用，普通任务保持原行为。
