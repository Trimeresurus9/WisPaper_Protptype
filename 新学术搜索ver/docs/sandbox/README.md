# Agent 云主机生命周期原型

2026-11-08，修改现有 `BrowserResearch` 工作台；未部署、未连接真实 Sandbox 服务。

## 预览

启动：`npm run dev -- --host 127.0.0.1 --port 5188 --strictPort`

普通入口：`http://127.0.0.1:5188/app/agent`，发送任务即可进入工作台。

评审入口：`http://127.0.0.1:5188/app/agent?workspace=1&prompt=探索多模态学习的研究方向&sandboxDemo=1`

环境信息浮层底部的「原型演示」可切换运行、休眠、不足 1min、永久保留、已休眠 30 分钟和已回收。切换会暂停当前输出演示，以免模拟休眠与任务执行同时发生。普通入口不显示该控件。

## 行为

- 右上角原终止按钮替换为环境图标按钮。点击打开环境信息浮层，在同一窗内查看状态、两个累计时长并调整保留策略。移除顶部横向状态条，恢复原工作台布局。任务生成状态与环境状态分别呈现。
- 环境在执行任务时不休眠；执行结束或暂停后空闲 60 秒进入休眠。
- 运行时长累计实际执行时间；环境已保留包括运行和休眠，回收后冻结。重建只重置环境年龄，不重置任务累计执行时间。
- 10 / 20 / 60 分钟从每次休眠开始起算。永久保留仍会休眠，但不自动回收。
- 修改保留策略不延后休眠起点，打开菜单不重置计时。缩短至已超过的时长需确认，取消保持原策略。
- 移除手动唤醒/重建按钮。休眠或已回收时，输入框保持可用；发送任意非空指令后先自动唤醒/创建环境，再执行同一条 query。仅编辑草稿不会唤醒环境，空白指令不会提交。准备期间显示进度，保留草稿并禁止重复提交，完成后清空输入。准备过程本地模拟为 900ms。继续回答演示、继续/重试网页任务仍经过环境准备。
- 环境回收使用绝对时间戳，后台标签页恢复后会按原到期时间补算。
- 移除回收信息卡片及底部解释，标题「任务环境」后新增 i 图标，悬浮或键盘聚焦时解释环境保留。到期前最后一分钟入口仍采用琥珀色提示。
- 桌面及窄屏均使用同一信息浮层。浮层自适应可用高度，过小时内部滚动；到期前入口显示琥珀色提醒。
- 选项采用 Radix 单选下拉菜单、浮层/确认对话框；支持 Escape、焦点恢复及键盘操作。

## 原型边界

状态只在当前挂载的任务会话内保存；刷新、离开任务或新建任务会重新初始化。没有实现真实永久存储、计费、权限或后端环境创建/删除。已有对话及示例文件仍属前端演示；未承诺生产环境回收后的数据保留范围。生产接入须由服务端提供环境状态、执行时段、创建/休眠/回收时间及保留策略。

- `npm run build -- --outDir /tmp/wispaper-query-wake-final-build`：通过。构建输出放临时目录，不覆盖原有 build；保留项目大 bundle 提示。

## 指令自动启动修订

休眠/回收时支持直接发送新 query；只将最后一条回答计入待响应状态，避免历史暂停回答阻塞新指令。旧回答保留暂停结果，后续生成期间不提供旧回答的继续/快进操作。

## 2026-11-10 显示修订

- 用户侧名称统一为「云主机」。状态与回收时间合并为一行，如「云主机运行中 · 10min 后回收 ▾」。
- 点击回收时间可选择 10min、20min、1h 或永久保留；菜单标注「休眠后保留时间」。运行中显示所选策略，休眠后显示剩余分钟。
- 累计运行与保留时长降为灰色小字，仅显示 min/h/d，不显示秒，不足一分钟显示 <1min。
- 10 项生命周期与时间格式测试通过；构建通过。浏览器确认下拉选项生效、永久保留、缩短时长确认与取消、说明提示以及 390px 浮层无溢出。
- 显示与计费均为前端原型，生产费率与扣费服务待接入。

## 云主机保留消耗

工作台右上角 Credits 总数打开消耗明细，常驻「云主机保留」项，含 0 值情形。Mock：任务执行 1,250 + 保留 12 = 1,262 Credits；`sandboxDemo=1` 入口可切换保留消耗为 0。累计记录独立于云主机状态，回收或重建不会清空。此展示不定义费率或真实扣费。
