# Ask AI 与 onboarding 收纳 · 2026-11-06

主原型：http://127.0.0.1:3000/ 。在「原首页」打开左下角 Mock，可开始 / 结束搜索体验，也可切换 Agent。没有新建独立原型。

需求参考：[003 - 全局 Ask AI](https://lcnm38332vyk.feishu.cn/docx/I9vUdarURoeG3VxiRcmcSh7TnOe) 第 1–2 节；文档后续附带的项目画布内容不作为本次新增范围。

## 行为

- 搜索与 Agent 气泡锚点从左侧导航移到真实输入框。兴趣步骤仍指向个性化设置；登录步骤回到首页输入区域。
- 关闭、稍后再说或 Escape：暂停当前引导，按「流程 + 步骤」去重保存到 Ask AI 的「继续了解」卡片。悬浮入口展示数量和短暂收纳提示。
- 卡片恢复原步骤，兴趣草稿保留；完成或重置引导会移除对应卡片。已开始的 Agent 任务中查看 Agent 引导不会清空主对话。
- 首页、知识库及其他普通页面使用右下角 Ask AI 悬浮抽屉；关闭后保留消息与草稿。
- 搜索结果使用右侧 Ask AI / 搜索过程；当前搜索有独立 UUID，同一次搜索刷新后保留上下文与会话。
- Agent 右侧提供 Ask AI Tab 和常用功能快捷入口。它只读取当前状态，消息、发送按钮与主 Agent 相互独立。
- 来源按场景提供 Product Help、我的知识库、Web 资源、所选文件、当前搜索或 Agent 状态。所有场景均支持新对话、历史列表、恢复与继续提问。
- 知识库批量选择后可直接进入 Ask AI，保存文献引用；附件控件仅关联本地文件名。原文献信息、笔记与评论栏继续保留。
- 空输入禁用发送；Enter 发送，Shift + Enter 换行，中文输入法合成期间不提交。回答失败可重试，不重复追加用户消息；上下文不可用时提示切换来源。
- Mock 默认左下角；窄屏开始引导后 Mock 收起到顶部，打开聊天后隐藏 Mock，避免遮挡输入与卡片。

## 原型边界

回答、搜索后续动作和登录均为本地模拟，未接入真实模型、网络检索、权限或文件解析服务。附件不上传；会话、草稿、卡片保存在当前浏览器。Agent 的进度读取现有原型公开状态；没有后端任务恢复。不同搜索 UUID / Agent 任务的聊天相互隔离。

实现文件：`src/components/ask-ai/AskAI.tsx`、`model.ts`、`SearchAskAI.tsx`、`ask-ai.css`，以及 App、onboarding、MockConsole、MyLibrary 和 Agent 工作台挂载点。
